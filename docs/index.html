Este é o opencode-marketplace: uma vitrine de plugins para o OpenCode. Você registra uma vez e instala cada plugin com um comando.

Você registra a vitrine no seu OpenCode, instala o plugin pelo nome e, quando sair versão nova, atualiza todos de uma vez.

Na vitrine, cada plugin tem a sua página, com o que ele faz e o comando para instalar. O primeiro é o memory, que dá memória entre sessões ao seu agente.

Como usar

Três comandos, cada um na sua hora.

Registre a vitrine

Uma vez só, no seu OpenCode.

opencode plugin marketplace add AllanSantos-DV/opencode-marketplace

Instale um plugin

Pelo nome, seguido de @opencode-marketplace.

opencode plugin install memory@opencode-marketplace

Atualize

Quando sair versão nova, todos de uma vez.

opencode plugin update --all
